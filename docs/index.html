Frequently asked questions

How do I hide sensitive information when screen sharing?

Install ScreenGuard in Chrome and turn on “I'm sharing my screen” before your call, or set it to always on. It blurs email addresses, phone numbers, card numbers and API keys in the pages you show, and blocks personal pages such as webmail and banking until sharing is off.

Does it work with Zoom, Google Meet and Microsoft Teams?

Yes. ScreenGuard works inside Chrome, so it protects whatever Chrome shows while you share a tab, a window or your whole screen in Zoom, Google Meet, Teams, Slack huddles or any other calling app. It cannot hide content in other desktop apps.

Does ScreenGuard send my browsing data anywhere?

No. ScreenGuard has no server, no account and no analytics. Link checks and sensitive-info detection run on your own computer. The only optional exception is Gemini visual detection, which is off by default and uses your own API key.

Is ScreenGuard free?

Yes. ScreenGuard is free and open source under the MIT license.

Will it block normal websites by mistake?

ScreenGuard is designed to stay silent on normal sites. Every warning can be overridden in one click, and you can keep your own list of allowed sites. If it gets a site wrong, the block page has a link to report it.
