matching block. Every store link has its own `utm_source`, so the Developer
Dashboard shows which directory brings installs.

Forms change. If a field here isn't on the form, skip it. If the form asks for
something missing here, the **Shared details** section probably has it.

```
ScreenGuard keeps sensitive info off your shared screen. Turn on screen-share mode before a Zoom, Meet or Teams call and it blurs emails, phone numbers, card numbers and API keys, hides personal tabs like webmail and banking, and stops phishing and risky links before they open. Free, open source, runs fully locally.
```

**Long description**
```
ScreenGuard is a free, open-source Chrome extension for anyone who shares their screen: sales demos, support calls, interviews, classes and live streams.

Flip "I'm sharing my screen" before a call, or leave it always on, and ScreenGuard:

• Blurs sensitive info in the pages you show: email addresses, phone numbers, card numbers and API keys, in page text and form fields.
• Blocks personal pages such as webmail, banking and chat until sharing is off.
• Stops risky links before they open, so a phishing, adult or gambling page never lands on the shared screen. Lookalike addresses like paypa1.com or paypal-login.com are caught, while real sites like google.fr are left alone.

Private by design: there is no server, no account and no analytics. Link checks and sensitive-info detection run on your own computer, and browsing history never leaves the browser. The code is MIT licensed on GitHub.

On normal websites ScreenGuard shows nothing at all. Every warning can be overridden in one click.
```

## AlternativeTo — alternativeto.net

Best value of the lot: people arrive looking for something to switch to.

1. Sign in → **Add application**.
2. Paste **Name**, **Website** (use the link below), the **Short description**, and the logo.
3. Platforms: **Chrome**, **Chromium**. License: **Free**, **Open Source**.
4. Tags: `screen-sharing`, `privacy`, `blur`, `chrome-extension`, `phishing-protection`.
5. After it's approved, open each app below and click **Suggest alternative** → ScreenGuard. Pick only ones that genuinely overlap:
   - SafeBlur
   - Obscuro
   - Privacy Screen
   - Malwarebytes Browser Guard (link-safety side only)

**Website link to use**
```
https://orvi2014.github.io/screenguard/?utm_source=alternativeto
```

## Launch directories (launchdirectories.com, smollaunch.com)

These list many smaller directories. Work through the ones marked free that accept
browser extensions, pasting the **Shared details** blocks, and change the
`utm_source` to the directory's name each time:

```
https://chromewebstore.google.com/detail/screenguard/dggihakhjjleajeimnfipcgbadkbjdcn?utm_source=DIRECTORY_NAME
```

Skip any that charge for a basic listing. At this stage, free listings and reviews
matter more.

## Microsoft Edge Add-ons — partner.microsoft.com

A separate store, and much less crowded than Chrome's.

1. Register in **Partner Center** (free for individuals) → **Edge** → **Create new extension**.
2. Upload `release/screenguard-1.0.17.zip`. It works unchanged.
3. Reuse everything from `store/LISTING.md`: name, description, the captioned screenshots, the promo tiles, and the privacy policy URL.
